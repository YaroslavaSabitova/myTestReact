#### для playwright:

`npx playwright test` — основная команда для запуска тестов, запускает все интеграционные тесты;

`npx playwright test --project=chromium `— запускает тесты только в Chrome;

`npx playwright test --debug` — запускает тесты в режиме отладки;
npx playwright codegen — автоматически генерирует тесты на основе действий пользователя;

`npx playwright test --headed` - запускаем тесты в видимом окне браузера, а не в фоновом режиме. Как только тесты закончатся, браузер автоматически закроется.

`npx playwright test --ui` — открывает интерактивный UI для запуска и отладки тестов. Там можно запускать отдельные тесты, ставить их на паузу, смотреть DOM-дерево на каждом шаге и «перематывать» тест назад;
